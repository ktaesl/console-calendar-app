# Console calendar app
This is console app that show calendar and give you posisbility to add event on Python.
* * *
## How to use this app
### Clone this repository.
```
git clone https://github.com/ktaesl/console-calendar-app.git
```

**or**

download zip
![download zip](screens\README\download_zip.png)

### launch

```
python3 main.py
```
